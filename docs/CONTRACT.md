# Elsewhere implementation contract

Plain browser ES modules, no dependencies; Node 22 static dev server. Parent owns UI, CSS, server, integration. Agents own designated files only. Original content; no copied game text or assets.

## Shared state (JSON serializable)
`{version:1,id,seed,rng,firstName,lastName,gender,country,city,age,year,alive:true,causeOfDeath:null,stats:{happiness,health,smarts,looks,discipline,karma,fame},cash,debt,education:{level:'none',enrolled:null,yearsLeft:0,grades:60,major:null},job:null,relationships:[],assets:[],investments:[],business:null,specialCareer:null,prison:{years:0,record:0,heat:0},skills:{fitness:0,music:0,acting:0,athletics:0,writing:0,coding:0,crime:0},conditions:[],licenses:[],social:{followers:0,posts:0},journal:[],achievements:[],history:[],flags:{},annual:{income:0,tax:0,expenses:0,net:0},pendingEvent:null,generation:1,ancestors:[],actionCounts:{}}`.

Relationship `{id,name,role,age,bond,alive:true,gender}`. Job `{id,title,salary,performance,years}`. Asset `{id,name,type,value,condition,rented:false,mortgage:0}`. Investment `{id,name,type,value,cost}`. Business `{name,type,value,capital,employees,performance,profit}`. Special career `{id,title,level,performance,earnings}`. Journal `{id,age,year,category,title,text}`. Pending event `{id,title,text,category,choices:[{label,effects:{cash?,health?,happiness?,smarts?,looks?,discipline?,karma?,fame?},result:string}]}`.

## Modules
`src/data.js`: export COUNTRIES array `{id,name,flag,cities,tax,cost}`, FIRST_NAMES `{female:[],male:[],neutral:[]}`, LAST_NAMES, JOBS array `{id,title,salary,education:'none'|'secondary'|'university'|'graduate',minSmarts,track}`, MAJORS array of strings, ASSETS array `{id,name,type,value}`, SPECIAL_CAREERS array `{id,title,description,skill,cost}`, EVENTS array `{id,minAge,maxAge,title,text,category,choices}` as above, ACHIEVEMENTS array `{id,title,description,icon}`, ACTIVITIES array (optional). At least 10 countries, 40 jobs, 45 original events. Agent may add fields, must preserve required ones.

`src/engine.js`: imports only data; exports `createLife(options={})`, `ageUp(state)` => new state, `resolveEvent(state,index)` => new state, `addLog(state,category,title,text)` mutates state, `random(state)` => 0..1 mutates rng, `clamp(n,min=0,max=100)`, `netWorth(state)`, `normalizeState(state)` => validated new state or throws, `continueLegacy(state,childId)` => new state. createLife options `{firstName,lastName,gender,country,city,seed,age}` default age 0; default London UK. Annual updates salaries/tax, age-based school, college progression, death, relationships, assets/investments, business/specialCareer profit, prison and event selection. Can repeat actions until actionCounts enforced by systems. Engine owns achievement checks exported `checkAchievements(state)` mutates. createLife default simple starting finances (0), first parents. normalize robust untrusted imports. No importing systems.

`src/systems.js`: imports data and engine; exports `getActions(state,category)` => descriptors `[{id,title,description,icon,cost?,disabled?:string,group?}]` and `performAction(state,actionId,payload={})` => `{state:newState,ok:boolean,message:string}`. Categories `education,career,relationships,activities,assets,finance,crime,special`. Action IDs globally unique and may encode target ids. getActions may list locked actions with disabled explanation. UI renders descriptors and invokes actionId. Validation required inside performAction, not just UI. Systems owns all non-annual actions. Use structuredClone. Attach action.dynamic form metadata if needed: `fields:[{name,label,type:'text'|'number'|'select',options:[{value,label}],value?}]`; UI collects payload, confirms details. Add `confirm` string for destructive actions. For relationship item actions use group relationship name. Generic actions should work with defaults without forms. Dynamic asset buy/sell, jobs, majors use encoded IDs.

Agents write meaningful Node tests in designated tests files. Use `node:test` and strict assert. Package type module will be set by parent.
