# Detailed character implementation contract (18 October 2026)

Parent owns app.js, styles.css, UI QA/server/Git. profile agent owns src/character.js + tests/character.test.js + docs/CHARACTER-MODEL.md. Engine agent owns engine.js/calendar.js and related tests. Systems agent owns systems.js/game-session.js and related new tests. Coordinate API changes directly; do not edit others' files.

Every human (player/relationship) gets fields:
- `birthYear`: new playable lives require integer year ≥1900 with 256 years of safe headroom. Starting age is any integer0–120; default birthYear=2026-age, year=calendarYearAtAge(birthYear,age). Parents may predate1900. Pre1900 playable save timelines migrate together to1900 retaining original-date metadata. Country/city labels are year-aware via countries.js; jobs and events share existing systems.
- `appearance:{skinTone,hairColor,hairStyle,eyeColor,description}` palette keys (not arbitrary CSS): skinTone `fair,light,medium,tan,brown,deep`; hairColor `black,brown,blonde,auburn,red,grey,white`; hairStyle `short,long,curly,wavy,bald`; eyeColor `brown,hazel,green,blue,grey`. Text <=300chars. Body/face details may extend later. Parent options `parents:{mother:{appearance:{description}},father:{appearance:{description}}}` with optional structured profile fields. Brief descriptions stored, common explicit hair/eye/style words may inform features, no traits inferred from appearance or demographics.
- `personality:{facets:{[key]:0..100},domains:{openness,conscientiousness,extraversion,agreeableness,neuroticism}}`. 30 IPIP-style facets (6/domain) with independent correlated continuous variation and deterministic per-character generation. Domain values ALWAYS recomputed mean of 6 facets. Exports PERSONALITY_DOMAINS entries `{id,label,color,facets:[{id,label,description}]}`. IDs: O imagination,artisticInterests,emotionality,adventurousness,intellect,liberalism; C selfEfficacy,orderliness,dutifulness,achievementStriving,selfDiscipline,cautiousness; E friendliness,gregariousness,assertiveness,activityLevel,excitementSeeking,cheerfulness; A trust,morality,altruism,cooperation,modesty,sympathy; N anxiety,anger,depression,selfConsciousness,immoderation,vulnerability. Realism means coherent simulation approximations, not validated diagnosis/test percentiles. Child profiles developing, not adult psychological assessment.
- `attributes:{iq,strength,stamina,agility,coordination,creativity,empathy,willpower}`. IQ 40..200 fictional age-normed estimate (mean100,SD15 generation); other ratings0..100 age-aware. IQ distinct from knowledge/school grades; old stats.smarts becomes knowledge display and still skill/qualification gates.
- `body:{heightCm,weightKg,bodyFatPercent,adultHeightCm,adultWeightKg}`. cm/kg/percent; plausible age-based growth generated deterministically. Ages<18 use growth, adult potentials stored internally for smooth ageing. UI edits current measurements only; infer potentials from edited current size. There is no future-target-age plan. No demographic/appearance link to intelligence/personality. Height/weight/BF all actual simulation fields. Export `bodyDefaults(age,gender,seed)` for age-aware defaults.
- `healthProfile:{cardiovascular,respiratory,immune,musculoskeletal,metabolic,mental,nutrition,sleep}`0..100. Export HEALTH_COMPONENTS `{id,label,description}`. stats.health is overall weighted aggregate for compatibility. Avoid pretending medically validated physiology.

## character.js pure module APIs
No engine/data/system imports. Independent seeded PRNG based on entity id/seed, must NOT consume global game rng (preserve deterministic old simulations).
- `ensureCharacter(entity,options={})` MUTATES entity, fills/normalizes missing detailed fields, preserves intentional custom values; options may contain overrides `appearance,attributes,body,healthProfile,personality`, parent profiles `parents` (array), seed. Uses entity.age/gender/stats where present. Idempotent. For pets keep existing species/health; human detailed profiles may be skipped (document animal distinction).
- `normalizePersonality(raw,seed)` returns complete personality, finite/clamped. Raw either `.facets` plus optional `.domains` or domain overrides? Domain overrides apply only to missing facets. Derived domains must not be independently trusted.
- `overallHealth(entity)` numeric aggregate.
- `reconcileCharacter(entity,beforeStats={})` MUTATES: legacy stats.health delta relative to beforeStats.health applies to components coherently; clamp all, synchronize aggregate. Does not treat knowledge gains as IQ gains. Can handle NPC no stats.
- `ageCharacter(entity,previousAge)` MUTATES body growth/ageing/physical attributes based on prior age and deterministic profile. Does not increment age itself. Does not randomly rewrite personality. Stable IQ estimate.
- `applyCharacterAction(entity,actionId)` MUTATES detailed physical/health/trait fields for meaningful exercise/diet/study/therapy/sleep/etc; called AFTER reconcileCharacter so intentional detailed changes survive. Does not increment action counts or journal, does not duplicate cash/legacy stat effects.
- `personalityCompatibility(a,b)` => score0..100, soft effect not destiny.
- `personalityModifier(entity,context)` => bounded multiplier typically0.85..1.15; contexts `learning,work,social,risk,recovery`.
- `describeAppearance(entity)` => short text respects custom description.

## Integration rules
Create: engine enriches player and parents after ordinary generation, applies options + options.stats whitelist. New humans generated systems.person() enriched after id/age set. Births can use parents soft inheritance. Every existing human upgraded by normalizeState; preserve unknown old flags and expected state shape v1.
Year: engine records beforeStats, applies ordinary annual effects, ageCharacter(player+living humans), reconcile aggregate; personality learning/work/recovery modifiers influence bounded outcomes. Conditions keep existing health penalties. Death/zero health remains honored. Import validates all new fields incl every NPC, calendar preserves BCE historical journal/history/ancestors. Legacy carries selected child's full profile/appearance/IQ/personality/body and correct birthYear rather than rerolling.
Actions: systems snapshots beforeStats, after action.execute enrich all newly created humans, reconcileCharacter(player,beforeStats), applyCharacterAction(player,actionId), then death/achievement checks. Relationship interactions/dating use both profiles soft compatibility and some relevant trait scores; IQ + knowledge influence learning/job success, strength/endurance influence sports/crime. No demographic bias gates. Minigame escape injuries reconcile components before death (capture beforeStats).

UI creation form sends opts with nested fields above, birthYear≥1900 and starting age0–120. Editing current character via exported engine `customizeCharacter(state,patch)` returning cloned normalized state; whitelist stats/appearance/attributes/body/healthProfile/personality and parent descriptions; log edit. Existing lives are customizable too.
